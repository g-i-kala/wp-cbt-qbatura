Motyw blokowy (FSE) dla pracowni projektowej Qbatura.

== Description ==

Typograficzny motyw odwzorowujący makietę HTML (html_design/). Realizacje, kategorie i pola
„Dane realizacji” dostarcza wtyczka Qbatura Core. Zalecane wtyczki: Advanced Custom Fields (Free),
Polylang, WS Form.

Struktura (szablony, części, wzorce, theme.json) jest tylko w plikach — nie edytujemy szablonów
w Edytorze witryny, bo zmiana zapisuje się w bazie i przesłania plik.
